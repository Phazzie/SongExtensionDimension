MESSAGE FLOW
════════════

User Action          Webview → Extension              Extension → Webview
───────────          ───────────────────              ───────────────────

Submit form    →     { type: 'generate',        →     { type: 'loading',
                       payload: formData }              payload: { message } }
                                               
                                               →     { type: 'updateSong',
                                                       payload: { song } }

Click Critique →     { type: 'critique' }      →     { type: 'loading',
                                                       payload: { message } }
                                               
                                               →     { type: 'critique',
                                                       payload: { critique } }

Click Export   →     { type: 'export',         →     Notification message
                       payload: { format } }           (success/error)

Error occurs   →     -                         →     { type: 'error',
                                                       payload: { message,
                                                                 suggestion } }
